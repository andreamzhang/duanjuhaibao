# 群像人物排版模式库（构图精髓）

> 用途：海报/封面的人物排布设计——诊断"呆"、选机制、写进提示词。
> 来源（2026-10 整理）：电影海报动态对称骨架分析（Geminianum）、8 种构图法实战（色彩韵）、海报设计 11 技巧（BFA）、StudioBinder 构图技法、深度透视系统群像提示词（OpenNana）、Shadow Ensemble 提示词模板。

## 一、构图精髓：骨架线 + 关系张力

- 构图不是"摆位置"，是用**看不见的骨架线**组织画面：对角 / 平行 / 垂直三族线（动态对称 armature）。经典海报里，人物肩线、视线、道具、标题都对齐到这些线。
- 群像的核心是**关系**：人物之间要有张力动作（对峙/结盟/密谋/窥视/守望），不是各自站岗。
- 一切服务一条**动线**：Z 形 / 对角 / S 形 / 纵深漏斗——让眼睛有路可走。

## 二、"呆"的五个病（诊断用）

1. 对称（左右镜像）· 2. 等距（均匀间隔）· 3. 同高（头在同一水平线）· 4. 同向（全部看镜头）· 5. 全正面（无侧身/遮挡/纵深）。

## 三、破呆五招

- 破对称 → 重心偏移 + 配重（一侧大块、另一侧小元素平衡；不对称但均衡）
- 破等距 → 疏密：组内挤紧、组间留白
- 破同高 → 错落：大小悬殊，不要所有头在同一水平线
- 破同向 → 视线成网：对视/侧望/垂目/窥视，**写明"谁看哪里"**
- 破全正面 → 侧身/半脸/背影/遮挡，制造纵深与神秘

## 四、群像排版模式库（选一，不混用）

| 模式 | 机制 | 结构 | 最适合 | AI 生成要点 |
|---|---|---|---|---|
| 对角对峙 | 对角骨架线 + 视线网 | 两大人物左下前 ↔ 右上中，视线交错成主对角；其余错落 | 对抗/夺权 | 写明"视线交错对视"，否则全员看镜头；加写『无人直视镜头』+ 防呆句（避免均匀间隔/排队/团队照） |
| 纵深行进 | 透视纵深 | 前景大 → 中景 → 远景小，尺度随距离递减，互相遮挡 | 归来/行进/史诗 | 写"前景/中景/远景、被柱影遮挡、从空间中出现"；防摊平 |
| 大脸聚焦 | 尺度悬殊 + 偏心 | 主脸占上 55–60%，其余为小注脚（侧影/半脸） | 人物驱动/心理向 | 大脸是相似度最稳构图；半脸写"黑暗中仅露半张脸与眼睛微光" |
| 关系簇拥 | 关系分组 + 疏密 | 按叙事成簇（同盟/密谋/独影），组内靠近有互动 | 权谋/群像剧 | 写"分三组、组内互动（对视/耳语/并肩）"，防摊平 |
| 背靠背 | 对称破格 | 双主角背靠背居中，朝向相反 | 双主角同盟 | 写"背对背、朝向相反"；两人肩线错开一点更活 |
| 剪影负空间 | 负空间图形化 | 人物剪影 + 大面积留白/纯色 | 概念海报 | 剪影放弃五官相似度，用轮廓特征（发型/道具）辨认 |
| 框架/门洞 | 框中框 | 门框/长廊框住人物，光线从框外进入 | 神秘/归来 | 写"透过门框/长廊看人物，边缘形成自然暗角" |
| 王座权力式 | 中心装置 + 权力差 | 一人坐/立于王座高处，其余低位环绕、明暗分化 | 权力主题 | 写"一人居中高位、其余低位环绕；中心最亮、四周压暗" |

## 五、AI 生成通用防呆句（写提示词时加入）

- "避免均匀间隔、排队或团队照构图"（avoid evenly spaced people, lineups, team-photo compositions）
- "人物与场景互相遮挡，部分人物被建筑/阴影部分遮挡"
- "尺度随距离自然递减"
- "姿态各异、有明确互动；避免所有人站桩"
- 视线写清楚：谁看谁、看哪边（视线成网的关键）

## 六、检查（出图后）

- **眯眼测试**：眯眼看黑白灰块——重心稳不稳、有没有一条动线
- **裁剪测试**：想象裁掉边缘 1cm，画面是否更完整（松了=内收）
- **视觉重量**：大块/亮色/复杂=重；用小块/暗色/简洁配平
- **五病复查**：对称/等距/同高/同向/全正面——至少破了三个
