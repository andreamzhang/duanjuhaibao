# 海报设计与审美手册（速查）

> 用途：写海报提示词前速查——把"设计语言"翻译成图像模型能执行的词。
> 来源（2026-10 整理）：Film Poster Design 完整指南（madegooddesigns）/ 40 光影术语实测（prompt-architects）/ Anthropic canvas-design / 《信条》海报多模态分析 / 优设 10 案例拆解 / 大岛依提亜专访 / AI 光影词汇研究（morphic、prompture）/ fantasy、stanchan 技能。


## 〇、总原则（先记这几条）

1. 一张海报只讲一件事：一个一级视觉母题；构图原型选定一个就"押注"，不脚踩两条船。
2. 内容为王：所有字体/颜色/版式/构图都为"一眼读懂主题"服务。
3. 对比产生焦点：明暗、冷暖、虚实、大小——每处对比都要有意图。
4. 留白是主动设计：标题和主视觉需要呼吸空间；拥挤 = 廉价。
5. 缩略图是最终战场：标题缩到约 200px 高仍要能读、主视觉仍要能认。
6. 精修 > 添加：不够好时先让已有元素更精，而不是加新元素（canvas-design）。

## 一、构图

- **显著性四工具**：大小、亮度、清晰度、位置——核心人物四项全占。
- **信息值**（《信条》分析）：上=理想/意象，下=真实/信息；中=主导，边=次要；左=已知，右=新。
- **构图原型（选一）**：大脸特写 / 剪影与负空间 / 群像浮头（保持一致的光与比例）/ 单一符号（戒指、面具、刀——高概念）/ 环境全景。
- **版式模式（选一）**：左右分栏 / 上下分栏 / 居中对称 / 对角线 / 三角-金字塔（群像）/ 框中框。
- **视觉动线**：用光、视线、线条把目光从主视觉引到片名。
- **群像**：金字塔或错落分层；主角最大最亮最清晰；后排接地+遮挡+同光系（不悬空、不"毕业照"）。
- **比例**：单人占高 60–80%；双人合计 65–85%；主角面部在画面上中部；标题安全区在下中窄幅。
- **平衡**：重元素（深色块、大图、密文字）要有轻元素配平；画面不能偏、不能飘。
- **群像排布模式库**（破呆五招 + 八式：对角/纵深/大脸/关系簇/背靠背/剪影/框架/王座）：见 `references/character-composition.md`。

## 二、色彩

- **三层配色**：底色系 60–70% + 辅助 20–30% + 强调色 ≤10%（强调色只给最重要的东西：主角、标题、核心符号）。
- **冷暖对比最有效**：冷暗环境 + 暖调主体（或反）→ 主体自动跳出。
- **低饱和底 + 高饱和主体**：背景压暗降饱和，主视觉提纯提亮。
- **橙青原理**（orange-teal）：让肤色（橙）与阴影/环境（青）对比最大化——动作/犯罪片的经典色。
- 色不过三系；金色/亮色只做点缀与标题，不铺满。

## 三、光影（提示词里最值钱）

- **别写"电影级/高级/完美打光"——实测几乎无效**。按顺序写：**方向 → 质感 → 光源 → 色彩氛围**。
- **方向**：正面 / 背面 / 侧光 / 侧逆（轮廓光 rim）/ 顶光 / 底光 / kicker 侧后点光。
- **质感**：硬光（边缘利落高对比）/ 软光（过渡柔和）/ 漫射 / 高光点（specular 反光）。
- **光源类型**（写"画内可见的实用光源"最有效）：烛光、吊灯、壁灯、火光、霓虹、窗光、月光、金色时刻。
  - practical light：点明画内光源，阴影就会像真实光源一样落下。
- **经典布光公式**（模型稳定响应）：伦勃朗光（45°主光+颧骨三角光）/ 明暗对照 chiaroscuro、tenebrism（高对比黑背景）/ 低-key（暗调+局部亮）/ 三点布光 / split（半脸）/ 蝴蝶光。
- **主体打光公式（直接套）**：主光（方向+冷暖）＋ 轮廓光勾边 ＋ 暗部保留细节 ＋ 画内光源入镜 ＋ 空气介质（尘/雾/烟/光柱）。
- **冷暖分工**：主光暖+环境冷（或反）= 电影感；全暖=复古温馨；全冷=压抑科技。

## 四、字体与字图关系

- **标题 = 定制品牌**：有质感、字重、特效的"标题设计"，不是随手打的字。
- 复杂画面配简单字体；简单画面用有性格的字体；标题缩到缩略图仍可读是底线。
- 字体情绪：衬线/宋=古典权贵；无衬线/黑体=现代力量；手写=情绪个人；黑帮题材→经典电影衬线。
- **字图关系五式**（fantasy）：压 / 穿 / 嵌 / 隔 / 退——避免"浮贴的说明文字"；标题与衣摆/暗部轻微遮挡更融合，但绝不压眼睛、嘴、核心道具。
- 标题占画面：常规 15–25%；巨型文字型 25–55%。
- 支撑信息（副题/署名）用安静系统字体，不跟标题抢；能不加就不加。

## 五、类型惯例速查

| 类型 | 色彩 | 字体/处理 | 构图偏好 |
|---|---|---|---|
| 犯罪/黑帮/复仇 | 黑+暗金+酒红/血红；low-key | 经典电影衬线、金属质感 | 群像对峙 / 大脸 / 单一符号（戒指、枪、王座） |
| 惊悚/悬疑 | 冷蓝灰+血红点缀；高对比 | 窄体、压抑衬线 | 孤立人物、窥视框景、框中框 |
| 动作 | 橙青、火色高光 | 粗窄无衬线、金属斜面 | 对角线、动势 |
| 爱情 | 粉紫/暖金、柔光 | 手写/圆润衬线 | 双人近距、负空间 |
| 剧情/获奖向 | 低饱和自然光 | 优雅衬线、克制 | 单一安静肖像 |
| 科幻 | 深蓝+霓虹 | 几何宽体无衬线 | 环境全景、对称 |
| 恐怖 | 黑+血红+病绿；高对比 | 破损/雕刻感字 | 怪异符号、负空间 |
| 喜剧 | 明亮高饱和高调 | 友好粗体 | 群像浮头、表情 |

## 六、空泛词 → 可执行词（提示词翻译表）

| 别写 | 改写 |
|---|---|
| 高级感 | 低饱和暗调 + 暗金点缀 + 大面积留白 |
| 电影级布光 | 暖调侧顶主光 + 冷调环境底光 + 侧后轮廓光 |
| 大片质感 | low-key、高对比、暗部保留细节、画内光源入镜 |
| 氛围感 | 空气尘雾 + 光柱/光晕 + 冷暖对比 |
| 主体突出 | 面部最亮最清晰 + 周围压暗虚化 + 色温对比 |
| 酷炫 | 具体道具/材质/光效（金属反光、烟雾、余烬、高光点） |

## 七、审美自查（出图后）

- **缩略图测试**：200px 高仍能读出"谁 + 什么情绪 + 片名"。
- **一眼测试**：3 秒内能说出类型、主角、冲突。
- **对比检查**：有明确的明暗/冷暖/虚实对比，且服务于主体。
- **重心检查**：画面不偏不飘，有明确视觉重心。
- **空泛词检查**：提示词里没有"高级/好看/完美"这类不可执行的词。
- **融合检查**：人物与背景同光系（方向、色温、环境光影响），没有贴图感。
- **精修检查**：优先让已有元素更精，而不是加新元素。
