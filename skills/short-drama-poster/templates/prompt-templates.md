# 提示词模板（短剧海报两步法）

> 用法：复制对应模板，把 <…> 换成该剧内容；人数按实际增减。七块结构（【人物主体】【排布】【背景】【光影氛围】【色彩】【标题文字】【画质】）不要省——每块都在防一类翻车。
> 出图后四步验收：① 逐字符核对片名（含标点）② 缩略图测试（缩到约 120px 宽仍能看清 C 位脸与片名）③ 检查多张脸是否融合走形 ④ 按版式骨架校正（标题安全区/对齐轴/间距，见 `references/poster-layout.md`）。

## A. 单角色姿势图模板

（每个角色单独生成一张，只喂该角色的白底设定图；竖版 3:4）

```
单人人像海报姿势图，竖版 3:4。严格参照所附参考图（白底多视图角色设定图：只提取人物相貌、发型、妆容、服装——<服装要点>，忽略其白色影棚背景与多格排版）。姿势神情：<站位/朝向/手势>，<表情与气质>；<外貌锚点：发色发型、瞳色、特征>。构图：<七分身（大腿以上）／半身（腰部以上）>人物居中，四周留呼吸空间。光影：电影级布光，柔和主光加<冷/暖>调轮廓光，面部受光清晰，<质感要点>细腻。背景：深灰黑色调、轻微烟雾与暗角，简洁不抢人物。画面不得出现任何文字、水印、第二个人物或影棚白底感。
```

姿势分配参考：
- 女主：站姿挺拔、身体微侧约 15 度、正脸直视、一手插兜，冷冽、下颌微扬（掌权者气场）
- 男首领/父亲：正面站立、双臂抱胸、微俯视（压迫感）；半身
- 反派女（艳）：身体微侧、单手叉腰、下巴微扬（挑衅冷艳）
- 反派女（年长/伪善）：站姿优雅、双手交叠身前、温婉微笑但眼神冰冷
- 配角：站姿笔直、双手自然垂放（克制）
- 若要手动抠图合成：把“深灰黑色调、轻微烟雾与暗角”换成“纯白背景”。

## B. 海报合成模板

（底图 = N 张姿势图 + 场景图；上传顺序与“参考图N”编号一一对应）

```
用于短剧平台封面与宣传的竖版 <3:4／9:16> 电影级短剧海报，<题材>，整体气质<气质词>，主色调<色系>，好莱坞<类型>电影海报质感。

【人物主体】参考所附<N>张单人姿势参考图中的人物形象，将<N>人组合到同一画面（保持各人相貌、发型、服装与姿态不变；忽略参考图各自的深色背景；允许小幅调整朝向以适配构图），重新统一布光，融合为一张完整海报——非拼贴、非分格、无白边。<主角A、主角B>两位主角占据画面最前、最大、最清晰的位置；除这<N>人外画面不出现其他人物：
① <女主角>（参考图1，女主角）：绝对C位——画面正中、最前、比例最大、最清晰，半身近景；<气质句>。
② <男主角>（参考图2，男主角）：紧挨<女主角>身侧（画面<右>侧）、半步靠后，与<女主角>共同构成画面中心的双主角主视觉；<气质句>；体量仅次于<女主角>，明显大于后排。
③ <反派1>（参考图3）：第二层（主角身后），画面<左>侧偏中；后排中戏份最多、最靠前、最大；<气质句>。
④ <反派2>（参考图4）：第三层，画面<右>侧偏后；<气质句>。
⑤ <配角>（参考图5）：最远层，画面<左>侧后方边缘、比例最小；融入暗部但仍清晰可辨。

排布与层级：按戏份由前到后为 ①→②→③→④→⑤；人物尺寸与面部清晰度按此顺序递减。五张面孔集中在画面中上部、五官清晰自然、互不混淆、不重复；人物剪影轮廓清晰可辨；视觉动线清晰（第一落点=主角面部，向下引导至片名）；后排人物有脚下接地、遮挡关系和同色温受光，不做悬空立牌、不做毕业照式平均排列；人物均不持武器，以神态与气场表达冲突。

【背景】<场景名>（可参考所附场景参考图）：<2-3个场景元素>。背景整体压暗、轻微虚化、低对比，仅作氛围衬托，绝不抢夺人物主体的视觉重心。

【光影氛围】电影感低-key 布光，按“方向→质感→光源→色彩”写具体：<主光方向+冷暖>、<环境底光>、侧后方暖色轮廓光勾边；画内出现实用光源（烛光/吊灯/霓虹等）；人物面部受光清晰、暗部保留细节；冷暖对比；空气中轻微尘埃与烟雾；高对比暗调。

【色彩】色彩关系：<底色系>占约 70%、<强调色>≤10%（只给主角、标题与核心符号）；人物暖调受光与冷暗环境形成冷暖对比；金色/亮色只做点缀，不铺满。

【标题文字】画面下方三分之一区域居中排版。片名必须逐字精确呈现（verbatim、不多不少一个字符）："<片名原文（含标点）>"——标点必须保留，字母拼写、大小写一律不得增删或改动；除片名自带的标点外，不得渲染任何多余符号（引号、括号等一律不出现）。两行排版：第一行 "<第一行，标点放行尾>"、第二行 "<第二行>"；第一行字号明显大于第二行，标题块整体约占画面下部四分之一。经典电影片名式衬线字体，金属浮雕质感，<金>色渐变，深色描边加微光晕；标题区为下中干净窄幅（不放脸、手、强纹理），背景干净压暗；标题不遮挡任何人物面部与核心道具、不贴边；标题可与人物衣摆/暗部产生轻微遮挡关系（不压面部），避免浮贴感。

【画质】高分辨率、海报级精细度、构图平衡、四周留安全边距；细节自然（首饰、衣料质感、手部正常）。视觉层级：人物主体＞标题＞背景；除上述标题外，画面中不得出现任何其他文字、水印、logo。
```
