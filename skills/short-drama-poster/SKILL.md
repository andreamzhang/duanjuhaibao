# 短剧海报（AI 提示词生成）

给用户的短剧做海报主视觉：用白底角色设定图先生成单角色“海报专用姿势图”，再用姿势图 + 场景图合成海报。多为海外短剧、英文片名。目录约定（示例，可自行调整）：`<项目根>/海报/` 下——`素材/` 放人物设定图与场景图、`素材/姿势图/` 放中间产物、提示词存 `海报提示词vN.md`（版本递增，旧版保留）。

## 硬性约定（每次都遵守）

1. **片名逐字符完全准确**：拼写、大小写、标点（如冒号）一个都不能少——用户的硬要求。两行排版时标点保留（冒号放第一行行尾）；出图后逐字符人工核对。
2. **主角层级显式写死**：主角关系先与用户确认，再写死站位——C 位 = 正中、最前、最大；次主角紧挨身侧、半步靠后；其余按戏份由近到远往后排、依次变小。不写清 AI 会平均分配权重，主体不突出。
3. **背景硬性弱化**：原样写“整体压暗、轻微虚化、低对比，仅作氛围衬托，绝不抢夺人物主体的视觉重心”。
4. **版式比例先确认**：3:4 与 9:16 都出现过（按剧/平台不同），不要沿用上一部剧的设定。
5. **超限图压缩**：压缩版放原路径、文件名加「_压缩」后缀，原图保留不覆盖。
6. **片名用双引号包裹**（Seedream 官方规则）：提示词里写 标题为"Mafia Princess: Back from Hell" 这类形式，并注明“逐字精确呈现（verbatim）、不多不少一个字符”；用 GPT-image 系模型时可再加逐字母拼写兜底。
7. **开头写明用途**（官方规则）：首句写“用于短剧平台封面与宣传的竖版海报”——标明图像类型与用途能显著提升贴合度。
8. **标题给尺寸约束**：字体/颜色/位置之外，加“第一行字号明显大于第二行、标题块约占画面下部四分之一”。
9. **刻意设计感**：加“强焦点、层级清晰、人物剪影轮廓可辨、光源方向明确（顶光＋侧后轮廓光）”——目标是“一张刻意设计过的海报”，不是随手拼图。
10. **缩略图验收**：成品缩到约 120px 宽（信息流尺寸）仍要能看清 C 位面部与片名——平台就是按这个尺寸评判封面的。
11. **群像不“合照”、后排不悬空**：四人以上只保核心 2-3 人最清晰，主角最亮最大；后排/边缘人物必须有脚下接地、遮挡关系和同色温受光——不能像悬空立牌、不能平均排列成“毕业照”。
12. **标题安全区**：默认下中窄幅干净区（不放脸、手、强纹理）；标题不得压主角眼睛、嘴或核心道具。
13. **审美语言具体化**：光影按“方向→质感→光源→色彩”写（如“暖调侧顶主光+冷调环境底光+侧后轮廓光，烛台作为画内光源”）；色彩写“底色系+1-2 个强调色（≤10%）”；构图写具体原型（中轴对称/金字塔/对角线）。禁用“高级感/电影级打光/完美光影”等不可执行词——写前速查 `references/design-aesthetics.md`。
14. **版式先定骨架**：写提示词/出图前，先按 `references/poster-layout.md` 定版式骨架——网格（12 列/边距≈6.7%/8pt 基准）、1 条对齐轴、标题组位置与字号关系（主:副≈4:2）、页脚区；出图后按骨架校正（标题重排/页脚/缩略图测试）。骨架图示例见 `assets/example-layout-blueprint.html`。
15. **人物排版禁用“毕业照”**：对称/等距/同高/同向/全正面五病至少破其三；群像必须有视线关系与纵深错落；从八式模式库选一（对角对峙/纵深行进/大脸聚焦/关系簇拥/背靠背/剪影/框架/王座）——见 `references/character-composition.md`。
16. **先判断剧，再设计海报**：不直接跳进提示词。写提示词前先做开题判断——题材路由 → 构成模型（1 主 + 至多 1 辅）→ 一级视觉母题（≤3 个意象选 1）→ 标题承载面（标题落在哪个物理面）；速查 `references/poster-concept.md`。海报必须守住题材承诺（黑帮要压迫与奢华、甜宠要暖要亮），不做背离题材的“高级化”。
17. **参考海报只借一个维度**：用户给的参考海报/他人剧照只用于分析，默认不直接喂给图像模型；单次最多借鉴一个维度（构图/配色/字图关系/质感择一），不复刻人物动作、场景骨架与标题字形。真实平台/品牌 logo、奖项桂冠、媒体引语、评分星标一律不出现（模型会自动加，负向约束写死禁止）。

## 流程

### 1. 读剧本、定层级、开题判断
- `.doc` 剧本直接读（Hermes `read_file` / Claude Code `Read` 均可自动提取正文）；先看人物小传，再通读全剧确认各角色戏份量。
- 产出顺序：主角（女主/男主）→ 反派 → 其余，按戏份排序——这就是海报上由前到后的站位顺序。
- **开题判断（先判断剧，再设计海报）**：题材与亚型、一句话核心冲突、情绪温度、一级视觉母题（≤3 个意象选 1）、构成模型（1 主 + 至多 1 辅）、标题承载面；速查 `references/poster-concept.md`，判断结果直接写进提示词的开场句与构图句。

### 2. 看素材
- 人物图常是“白底多视图角色设定图”（四联：特写 + 正/背/侧全身，影棚白底、无文字）；另有场景参考图。
- 大图（4K、8–10MB 级 PNG）直接交给视觉工具容易超时，先压到约 1200px 宽 JPEG 再分析：

```python
from PIL import Image
im = Image.open(src).convert('RGB')
im.thumbnail((1200, 1200), Image.LANCZOS)
im.save(dst_jpg, 'JPEG', quality=82)
```

- 设定图在海报提示词里必须注明：“只提取人物五官、发型、服装与气质，忽略其白色影棚背景与多格排版”——不写会把白底/四格带进海报。

### 3. 两步法生成
**第一步：单角色姿势图**（每个角色单独生成一张，只喂该角色的设定图；竖版 3:4）
- 模板见 `templates/prompt-templates.md` A 节；姿势按角色定位分配（女主挺拔冷冽、男首领抱胸俯视、反派女叉腰挑衅等）。
- 深灰黑背景 + 烟雾暗角（利于合成融合；若要手动抠图则改纯白背景）；布光按“方向→质感→光源”写具体 + 轮廓光；不得出现文字/水印/第二人物/影棚白底感。
- 多抽几版，挑“脸最像设定图、手部正常”的再进下一步——姿势图是海报的脸部保险。

**第二步：用姿势图合成海报**（N 张姿势图 + 场景图；上传顺序与“参考图N”编号一一对应）
- 七块结构：人物主体（逐张映射 + 定位）/ 排布与层级 / 背景 / 光影氛围 / 色彩 / 标题文字 / 画质；模板见 `templates/prompt-templates.md` B 节。
- 必写句：组合到同一画面、保持相貌服装姿态不变、忽略参考图各自背景、重新统一布光——**非拼贴、非分格、无白边**；单张独立输出（不要拼图/四宫格/接触表）。
- 参考图数量受限时优先保女主角 + 主要反派，其余改用文字描述。

### 4. 出图后核对（验收清单）
- **片名逐字符**核对（拼写、大小写、标点含冒号）——一票否决项。
- **人脸**：多张脸不互相融合/走形；主角脸与设定图相似度可认（不像 → 重抽或回炉姿势图）。
- **层级**：C 位最大最亮最清晰（第一视觉落点）；五病至少破三、眯眼测试有动线；后排接地不悬空、不“集体照”。
- **缩略图**：缩到约 120px 宽仍能看清 C 位面部与片名。
- **标题安全区**：不压脸/手/核心道具、不贴边；按 `references/poster-layout.md` 骨架校正标题组与页脚。
- **画面干净**：无多余文字、水印、平台 logo、奖项标识、媒体引语小字。
- 错了重抽；片名反复翻车 → ① 图像编辑指令改字（保持配色/字体/对齐不变）② 无字底图 + 标题层分层兜底 ③ 后期加字（用户合成流程最稳）。

### 5. 上传限流（生成工具常限单图 10MB）
- 超限判定用 Windows 显示口径（MiB）；跑 `scripts/compress_images.py <素材目录>`：PNG 无损优化 + 必要时按 96%/93%… 逐档缩放到 ≤9.5MiB（同时低于 10MiB 与 10MB 两种口径）。
- 压缩版加「_压缩」后缀放原路径，原图保留。

## 进阶兜底：分层封面工作流（底图/标题分开做）

- 适用：标题反复翻车，或想让标题层能反复重做而不动底图。
- **底图层**：先生成无字海报底图（人物/场景/光影），并给标题预留可落位的干净面——“标题承载面”（暗部色块、雾气、磨砂玻璃、地面反光、墙面等）在底图阶段就定好；低到中对比、暗部保留细节，不要焦黑/重 HDR/强暗角。
- **标题层**：单独生成/单独处理——① 图像模型生成的标题设计层（只含剧名等指定文字；纯黑背景浅色字，或纯白背景深色字；无乱码、无多余小字）；② 规范排版单独导出的透明文字层（用户流程）。模板见 `templates/prompt-templates.md` C（无字底图）与 D（标题层）。
- **合成**：按网格定位叠加——黑底白字用 screen、白底黑字用 multiply；本地只做裁剪/缩放/移动/透明度。跑 `scripts/composite_layers.py`（自动输出 grid.json，记录全部参数）。
- 网格参考（1080×1920）：主视觉 5%–64% / 标题区 64%–80% / 页脚 84%–92%；3:4（1080×1440）分区见 `references/poster-layout.md`。
- **产出四件套**：底图层、标题层、合成图、网格 JSON——标题层可单独复用。
- 好处：底图不重跑，标题错了只重做标题层。

## 坑
- 设定图白底/多格排版被带进海报 → “忽略白底与多格排版”这句不能省。
- 主角/反派关系不显式 → 提示词会被判定“没读懂谁是主角谁是反派”打回；层级、站位、大小都必须写明。
- 英文片名丢字母/丢标点是高频事故 → 提示词写“逐字符锁定、不得增删改”，出图后人工复核；发往生成工具前可跑 `scripts/check_prompt.py` 预检。
- 模型自动加戏：电影节桂冠/奖项、媒体引语、平台 logo、虚构真实人名 → 负向约束写死禁止；多张任务会被合并成四宫格/拼图 → 写明“单张独立输出”。
- 大图直传视觉工具超时 → 先压小再传，固定动作。
- 比例自作主张 → 先确认。

## 支持文件
- `templates/prompt-templates.md` — 姿势图模板（A）+ 海报合成模板（B）+ 无字底图模板（C）+ 标题层模板（D），复制改填。
- `scripts/compress_images.py` — 批量压超限图（原路径 +「_压缩」后缀，原图保留）。
- `scripts/composite_layers.py` — 分层合成：screen/multiply/normal 混合 + 网格定位，输出 grid.json（分层兜底用）。
- `scripts/check_prompt.py` — 提示词预检：片名逐字核对、违禁词（电影节/平台/品牌）、空泛词告警。
- `references/design-aesthetics.md` — 海报设计与审美手册（构图/色彩/光影/字体/类型惯例/空泛词翻译表/审美自查）。
- `references/poster-layout.md` — 海报版式（排版）系统手册：网格/对齐/层级/间距/留白/阅读路径/版式原型/电影海报规格/校正步骤，含可直接套用的数值。
- `references/character-composition.md` — 群像人物排版模式库（构图精髓）：破呆五招 + 八式排版模式 + AI 防呆句 + 眯眼/裁剪检查。
- `references/poster-concept.md` — 海报概念系统手册：开题判断 / 10 构成模型 + 决策树 / 短剧题材路由表 / 标题承载面与标题原型 / 参考与原创边界 / 题材承诺。
- `assets/example-layout-blueprint.html` — 版式骨架示例（12 列网格 / 标题组 lockup / 分区标注）。
- `assets/example-character-arrangement.html` — 人物排版四方案示例（对角对峙/纵深行进/大脸聚焦/关系簇拥）。
