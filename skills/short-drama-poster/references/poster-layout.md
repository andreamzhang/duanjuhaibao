# 海报版式（排版）系统手册

> 用途：给海报定"版式骨架"——先定骨架，再写提示词/合成。数值可直接套 1080×1440（3:4）画布。
> 来源（2026-10 整理）：Figma/PS 海报排版教程系列（素材集市）、优设《18000字版式基础》、海报网格解析（树叶云）、《Design Shack》海报解剖、Adobe 海报指南、owl-listener 版式套件、zeke 瑞士设计系统。

## 〇、版式的本质

- 版式 = 用**网格 + 对齐 + 层级 + 间距**给信息排出秩序。
- 流程：**先大后小、先整体后局部**——① 大块空间分割 → ② 每块二次划分 → ③ 细节。先用灰块占位确认层级与阅读路径，再做装饰。
- 做版式先锁三件事：**锁网格、锁对齐轴、锁层级**——再谈好看。

## 一、网格（骨架）

- 列数：海报常用 6/8/12 列；信息少用 6，标准用 12。
- 参数模板（1080×1440）：12 列；边距 72–80px（≈画布宽 6.7–7.4%）；Gutter 24px；列宽 =（1080−2×72−11×24）/12 = **56px**。
- 基线网格：8px 基准——**所有间距取 8 的倍数**（8/16/24/32/48/64）。
- 页边距经验：短边的 1/8–1/6；上下边距 ≥ 左右边距。
- 模块化网格：列×行成模块；元素跨列/跨行合并（主视觉跨 6–8 列、标题跨 8–10 列）。
- 破格：允许少量元素出血/越界（色块延到边缘），"破格 × 对齐"形成对比。

## 二、对齐

- **一条主轴线原则**：整张海报只用 1–2 条对齐轴；居中（电影海报最常用）或左对齐（信息型），不混用。
- 关键元素都贴列线：标题、主视觉边缘、页脚落在同一条中轴/列线上。
- 光学对齐：视觉重量平衡优先于数学对齐。
- 成组对齐：同组元素共享边距与间距（lockup 思维）。

## 三、层级（Type Scale）

- 3–4 级足够：主标题（最强）→ 副题/宣传语 → 关键信息（日期/署名）→ 补充。
- 字号关系：**主标题 : 副题 : 正文 ≈ 4 : 2 : 1**。
- 数值（1080×1440）：主标题 72–110px（Bold/ExtraBold）；副题 28–36px；正文 16–18px；辅助 12–14px。
- 行距：标题 = 字号 ×1.05–1.2（越紧越"海报"）；正文 = ×1.4–1.7。
- 字距：大标题收紧（-10~0）；小字/全大写加宽。
- 字重：主标题 SemiBold/Bold+，副题 Medium，正文 Regular——别全部同一字重。
- 缩略图底线：主标题在约 200px 高的缩略图上可读。

## 四、间距（节奏）

- 8pt 分级（照抄）：组内 8/16 → 标题-副题 16/24 → 段落间 24/32 → 大模块间 48/64。
- **亲密性**：相关越近、无关越远；标题与副题"抱团"，标题组与外部元素拉大距离。
- **边距 > 内部间距**：画面边缘留白永远大于内部缝隙。
- 检查：全部间距只用 2–3 个固定数值，不要每块都不一样。

## 五、留白

- 目标留白约 40%；商业海报可压缩，但主标题区周围留白 ≥ 标题高度的 1–2 倍。
- 留白是有比例的设计元素，不是剩余空间。
- "加比感觉更多"：不够高级时先把**元素减 30%、间距加 20%**。

## 六、阅读路径

- 电影海报标准路径：**中心轴、从上到下**——主视觉（人/物）→ 标题组 → 页脚信息；3 秒内可扫到"标题+主视觉"。
- 信息型用 Z 型（左上→右下）；海报型用中轴（居中向下）。
- 视觉动线：用光、视线、线条把目光引到标题。

## 七、版式原型（选一）

| 原型 | 结构 | 适用 |
|---|---|---|
| 上图下文 | 主视觉占上半区 55–65% 高；标题组下三分之一 | 最稳、最"电影" |
| 居中大标题 | 标题居中放大（可占宽 60–90%），主视觉退为背景 | 气质型 |
| 左图右文 | 图 7 列 + 文 5 列；文字栏宽 8–12 汉字/行 | 信息密集 |
| 满版+角标 | 主视觉铺满，文字压四角/下缘 | 广告型 |
| 模块化网格 | 多图/多信息，元素跨列合并 | 群像/多物料 |
| 巨型文字 | 标题即主视觉（占 25–55%） | 概念型 |

## 八、电影海报专用规格

- 层级顺序（观众阅读序）：**主视觉 → 主标题 → 宣传语 → 演员/署名 → 页脚**。
- 标题安全区：下中窄幅（左右留 ≥ 边距），不放脸/手/强纹理。
- 标题组 lockup：主标题 + 副题（可选）间距 16–24；**主标题 ≤2 行**；换行在语义处（如冒号后）。
- 页脚区：密小字（billing block 式），居中，字号 ≤ 画面 2.5%，压缩行距；与标题组间距 ≥48。
- 3:4 竖版（1080×1440）分区参考：主视觉 6%–70% → 标题区 70%–86% → 页脚 86%–94% → 底边距 6%。

## 九、出图后的版式校正（后期）

1. 套骨架检查：标题是否落在安全区、是否压脸。
2. 重排标题：按 lockup 规格重做（网格对齐、字号关系、间距）。
3. 加页脚：日期/署名/角标小字排到页脚区。
4. 缩略图测试：120–200px 宽检查可读性。

## 十、检查清单（照抄）

- 是否只有 1–2 条对齐轴？
- 字号是否形成明显 3 层？
- 所有间距是否大多为 8 的倍数？
- 边距是否 ≥ 内部间距？
- 主标题是否 ≤2 行、缩略图可读？
- 颜色是否 ≤3 个主要色？
- 3 秒内能否扫到标题/主视觉？
- 修复口诀：**"散"→收窄内容宽度+加留白；"乱"→减字体（≤2 种）减色；"不高级"→减元素 30%、间距加 20%。**
