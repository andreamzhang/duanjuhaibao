# 海报概念系统手册（开题 → 模型 → 路由 → 标题承载）

> 用途：写提示词前的“判断”环节——先判断剧，再设计海报；一张海报只押一个概念。
> 来源（2026-10 整理）：fantasy-movie-poster-skill 的构成模型 / 决策树 / 题材路由 / 标题承载面方法论，适配短剧流程；配合 `design-aesthetics.md`（审美）、`poster-layout.md`（版式）、`character-composition.md`（群像内部排布）使用。

## 〇、开题判断（写提示词前过一遍）

1. **题材与亚型**：黑帮权力 / 豪门复仇 / 狼人·吸血鬼 / 甜宠·先婚后爱 / 悬疑惊悚 / 重生穿书 / 家族伦理……
2. **受众与场景**：海外短剧信息流——3 秒读懂、缩略图能打。
3. **情绪温度**：冷/热、克制/爆裂、暗黑奢华/暖甜明亮。
4. **一句话核心冲突**：主角要什么、谁挡着。
5. **人物关系**：单人 / 双人 / 群像 / 人与空间 / 人与物。
6. **一级视觉母题**：意像是总库里只挑 3 个候选，最终只押 1 个主母题（戒指、王座、信物、眼神、雨夜、旧照片……）。
7. **构成模型**：1 主 + 至多 1 辅（见第一节）。
8. **标题承载面**：标题落在哪个物理面（见第三节）。

判断结果直接写进提示词的“开场句 + 构图句”，不要停留在脑内。

## 一、构成模型库（选 1 主 + 至多 1 辅，禁止叠三种）

| # | 模型 | 机制 | 适用 |
|---|---|---|---|
| 1 | 电影静帧型 | 事情刚发生/将发生，人物不看镜头 | 剧情瞬间、双人距离 |
| 2 | 巨型标题型 | 标题承担空间压力，占画面 25%–55% | 标题即主视觉的概念款 |
| 3 | 手写介入型 | 手写体只承担主标题或一句心理文字（英文签名体同适用） | 爱情、青春、记忆 |
| 4 | 单一物件隐喻型 | 围绕戒指/钥匙/信物/面具/印章组织 | 高概念、悬念 |
| 5 | 极端人物裁切型 | 大脸/眼神占画面上 55–60%，其余作注脚 | 心理向；相似度最稳 |
| 6 | 负空间小人物型 | 人物占画面 5%–20%，大量留白/环境 | 孤独、史诗感 |
| 7 | 群像结构型 | 核心/关系/阵营三层级，站位表达权力 | 权谋、家族、帮派 |
| 8 | 空间秩序型 | 透视/对称/长桌/门洞/队列形成权力结构 | 制度压迫、审判 |
| 9 | 临场窥视型 | 镜头像角色眼睛：门框/车门/头盔/监控边缘进前景 | 悬疑、窥视 |
| 10 | 拼贴绘画实验型 | 油画/丝印/网点/错位，必须与剧情直接相关 | 概念款，谨慎用 |

短剧常用：单主角 → 5 / 3 / 10；双主角 → 1 / 6；群像 → 7（+4）；黑帮·豪门 → 7 + 4 或王座权力式；悬疑 → 9 + 4；甜宠 → 1 / 3。

## 二、决策树（故事形态 → 模型）

- 一个人的心理 / 复仇 → 极端裁切（5）
- 两个人之间的距离 → 电影静帧 / 负空间关系（1 / 6）
- 多人互相牵制 → 群像结构（7）
- 一个空间在控制人 → 空间秩序（8）
- 一个物件代表整部剧 → 单一物件（4）
- 一次行动 / 临场处境 → 临场窥视（9）
- 标题就是最强识别 → 巨型文字（2）
- 主模型确定后，最多再加 1 个辅助模型（如 群像 + 物件、负空间 + 手写），禁止三种叠加。

## 三、短剧题材路由表

| 题材 | 母题 | 构图 | 标题字体 | 色彩 | 避免 |
|---|---|---|---|---|---|
| 黑帮 / 权力复仇 | 王座、戒指、家族徽记、雨夜 | 群像对峙 / 王座权力式 | 经典电影衬线（Trajan/Cinzel 气质） | 黑 + 暗金 + 酒红 | 廉价警匪感、武器堆砌 |
| 豪门 / 复仇逆袭 | 玻璃幕墙、回望、升格瞬间 | 对角对峙 / 大脸聚焦 | 高对比衬线 | 深蓝黑 + 香槟金 / 血红点 | 都市剧感、影楼婚纱 |
| 狼人 / 吸血鬼 / 超自然 | 月亮、爪痕、血色、古堡 | 大脸 + 半脸、剪影 | 窄体衬线 / 雕刻感 | 冷蓝月 + 血红 | 恐怖片直给、廉价特效 |
| 甜宠 / 先婚后爱 | 距离、暖光、日常小物 | 双人不对称、负空间 | 优雅衬线 / 轻手写 | 奶油白 + 蜜金 + 浅粉 | 糖水滤镜、过度甜腻 |
| 悬疑 / 惊悚 | 门缝、监控、缺席者 | 窥视框景、单物件 | 窄体 / 切割无衬线 | 冷青灰 + 血红点 | 鬼片跳吓、脏黑 |
| 重生 / 穿书 / 逆袭 | 今昔错位、镜像 | 电影静帧、对称破格 | 粗窄无衬线 | 两色对撞 | 综艺封面、彩虹堆色 |
| 家族伦理 / 背叛 | 餐桌、空椅、合影变体 | 群像关系簇 | 克制衬线 | 木褐 + 烟灰 | 生活剧感 |

配色底线：1 个主色系 + 至多 2 个辅助 + 1 个强调色（≤10%）。

## 四、标题承载面与标题原型

标题不能“浮贴”——**底图阶段就要给标题找好物理落点**：

- 承载面清单：天幕/墙面/门洞、磨砂玻璃/雾气、地面反光、暗部色块、帷幕/旗幔、桌面、金属牌匾。
- 顺序：先定承载面 → 再让底图与提示词为它留出干净窄幅（默认下中）。

标题原型（选一，默认第 1 条）：

1. **下部居中锁字**：最稳、短剧主流（现有 B 模板即此式）。
2. **巨型标题压景**：标题即主视觉（占 25%–55%），可压在人物/场景上。
3. **物件锚点**：标题落在画内物件上（牌匾/镜面/桌面/车门）。
4. **签名手写**：爱情/青春向，手写体 + 小字系统。
5. **竖排窄条**：东方题材；英文标题慎用。

标题与主视觉可轻微叠压（衣摆/暗部），不压面部、眼睛、嘴、核心道具；避免“礼貌浮贴”。

## 五、参考与原创边界（用户给参考海报/剧照时）

- 可学（抽象 DNA）：主体占比、镜头距离、光线方向、冷暖比例、留白方式、字体尺度、信息密度、媒介质感。
- 不可复制：人物身份+动作同时一致；人物关系+场景骨架同时一致；标题位置+字形+主配色同时复用；标志性道具组合。
- **单次最多明确借鉴一个维度**（构图 / 配色 / 字图关系 / 题材 / 质感 择一），其余重新设计。
- 默认参考图只用于分析，不直接作为图生图输入；用户明确要求修改某张图时，才走图像编辑流程。

## 六、题材承诺（硬规则）

海报必须交足题材承诺：黑帮给压迫与奢华、甜宠给暖与甜、悬疑给不安。不要为了“高级”背离题材（把爽剧做成阴郁空场文艺片）——要做的是在题材的原始气质里“高级化”，不是换赛道。参考图做不到精确复现时，做“清晰的主题衍射”，不做“像但不准”的中间态。
